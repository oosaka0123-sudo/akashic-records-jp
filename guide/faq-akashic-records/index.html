アカシックレコードQ&A

検索されやすい疑問を短く整理しました。詳しく知りたい項目は、各専門記事へ進めます。

01

基本

アカシックレコードとは？

宇宙や人間の出来事・経験・情報が記録されていると考える近代神秘思想上の概念です。詳しく読む →

アーカーシャと同じ？

同じではありません。アーカーシャは古いインド思想の語で、近代の「アカシックレコード」は後世の西洋神秘思想の再解釈を含みます。詳しく読む →

宗教ですか？

特定の一宗教そのものではありません。神智学、人智学、ニューエイジなど複数の思想潮流と関係します。

02

アクセス・リーディング

誰でもアクセスできますか？

可能だとする流派はありますが、客観的に能力を確認する標準的方法はありません。リーディングとは →

未来は読めますか？

未来を読むとする実践はありますが、予測精度が科学的に確立しているわけではありません。未来は決まっているのか →

前世は分かりますか？

前世情報を得られるとする主張はありますが、内容の真偽を客観的に検証できるとは限りません。前世は読めるのか →

危険はありますか？

不安を煽る断定、高額契約、医療や生活上の重要判断の代替にすることは避けるべきです。安全な向き合い方 →

03

体験

夢はアカシックレコードですか？

そう解釈する人はいますが、夢は睡眠中の心的体験として科学的研究の対象でもあります。夢との関係 →

デジャヴは前世の記憶？

その解釈はありますが、心理学では親しさや記憶の評価に関わる現象として研究されています。既視感との関係 →

ハイヤーセルフと同じ？

同じではありません。ハイヤーセルフは「高次の自己」、アカシックレコードは「記録・情報の領域」として語られることが多いです。詳しく読む →

04

科学・比較

量子力学で証明されていますか？

いいえ。量子力学からアカシックレコードの存在が直接導かれるわけではありません。詳しく読む →

阿頼耶識と同じ？

似た比喩で語られることはありますが、唯識思想の阿頼耶識と近代西洋のアカシックレコードは歴史的背景も理論も異なります。詳しく読む →

集合的無意識と同じ？

同一ではありません。ユングの集合的無意識は心理学史上の概念で、宇宙的な出来事の記録庫を意味しません。詳しく読む →

05

歴史

誰が広めたの？

神智学、人智学、エドガー・ケイシー系の思想、ニューエイジ文化など複数の流れがあります。歴史年表 →

リードビーターは何をした？

『Clairvoyance』などで、過去を見ることをアカシックレコードから読む仕組みとして詳述しました。人物記事 →

ニューエイジで何が変わった？

宇宙論的な概念から、個人の自己探求・人生目的・前世・リーディングへ重点が移る傾向が強まりました。詳しく読む →
