SPECIAL FEATURE / ARCHIVE MEMORY

記録するという、
人類の欲望。

記録は残すだけではありません。集め、分類し、探せるようにし、次の世代へ渡す。その仕組みとして図書館や文書館は発達してきました。完全な記録を夢見る想像力と、現実のアーカイブの限界を見ます。

HOME/ARCHIVE MEMORY

01 / ARCHIVE

記録は、
選ばれて残る。

史実

図書館、文書館、博物館などは、人間社会が情報や資料を保存し、整理し、再利用するために作ってきた制度です。しかし、あらゆる出来事が等しく残るわけではありません。収集方針、権力、予算、災害、媒体の劣化によって、記録には必ず欠落があります。

その不完全さがあるからこそ、「すべてが残る記録庫」という発想は強い魅力を持ちます。

02 / ARCHIVAL CHAIN

記録が残るまで。

01

CREATE

出来事が文書、写真、音声、映像、データとして記録される。

02

SELECT

保存するものと廃棄するものが選ばれる。

03

DESCRIBE

名称、年代、作者、由来などの情報が付与される。

04

PRESERVE

媒体の劣化や技術の陳腐化から記録を守る。

05

ACCESS

目録や検索によって、必要な記録へ到達できるようにする。

03 / PERFECT ARCHIVE

完全な記録庫は、
人類の外にあるのか。

現代解釈

アカシックレコードを「宇宙の図書館」と呼ぶ表現は、アーカイブの仕組みを借りた比喩です。保存、検索、アクセスという現代的な概念が、神秘思想の説明に持ち込まれています。

科学的知見

現実の図書館やデータベースと違い、宇宙的な記録領域が存在し、個人がそこへアクセスできるという主張は再現可能な科学的証拠によって確立されていません。
